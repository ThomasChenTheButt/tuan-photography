# Sources: where eye-catching openings can be studied

Written once by the source finder (2026-10-08) and reused by later runs. Each scout has its own
hunting ground; "readable" says whether an agent can read useful detail there (words or code
about HOW the opening moves), not just look at pictures or video. Several code sites refuse a
plain fetch (Cloudflare) but open normally in the browser tool: marked "browser".

| Scout | Source | URL | What it offers | Readable |
|---|---|---|---|---|
| 1 | Awwwards collection: Loading page | https://www.awwwards.com/awwwards/collections/loading-page/ | 542 preloaders and intros as short videos with tags and a link to the live site; the words are thin, the value is the live link, whose DOM and JS can be read | no (video + tags; follow the live link) |
| 1 | Awwwards collection: Transitions | https://www.awwwards.com/awwwards/collections/transitions/ | page-to-page and cover-to-content transitions, same format; sister search https://www.awwwards.com/inspiration_search/?text=intro lists award-winning "intro" sites | no (video + tags; follow the live link) |
| 1 | CSS Design Awards | https://www.cssdesignawards.com/ | daily winners with a one-line description, judge scores in UI / UX / Innovation and the live link; e.g. /sites/bulles/50187/ | no (one line + scores) |
| 1 | The FWA: cases | https://thefwa.com/cases | award cases with an "about the project" text on idea and tech, credits and the live link; page is JS-rendered | yes (browser) |
| 1 | Hoverstates | https://hoverstat.es/ | hand-picked unusual sites, each with one written paragraph naming the exact device (a dial navigation, a scattered stack that orders itself, fuzzy SVG type coming into focus) | yes |
| 1 | School of Motion: 10 websites with great animation 2026 | https://www.schoolofmotion.com/blog/10-websites-with-great-animation-in-2026 | a motion school describing in words what moves on Epic, Unseen, Lusion, Active Theory and others; moderately detailed, good as a reading list of sites to open | yes |
| 2 | Art of the Title | https://www.artofthetitle.com/ | the archive of film and TV title sequences: 5,000-word interviews, shot-by-shot descriptions, storyboards, typography notes (e.g. /title/severance/); 254 designer pages at /designers/ | yes |
| 2 | Motionographer | https://motionographer.com/ | motion-design news and interviews; opening-title pieces describe the move in words (an infinite zoom, colour entering a monochrome world), e.g. /news/nexus-studios-unveils-opening-titles-for-playgrounds-in-motion/ | yes |
| 2 | Imaginary Forces | https://www.imaginaryforces.com/ | studio behind many main titles; project pages carry a concept text and the director's words on the movement, e.g. /project/star-city, /project/war | yes (moderate) |
| 2 | Sarofsky | https://www.sarofsky.com/work | Chicago title studio (Marvel, Superman); each project has a written case text on approach and sequence | yes |
| 2 | Watch the Titles (Submarine Channel) | https://www.watchthetitles.com/ | 200+ sequences by medium with short designer interviews; mostly embedded video, use it to find titles and read them at Art of the Title | no (video; thin text) |
| 3 | Codrops demos: intro, preloader, page-transition | https://tympanus.net/codrops/demos/?tag=intro | every demo has an article and downloadable HTML/CSS/JS source; also ?tag=preloader and ?tag=page-transition; a decade of reveal, slice, clip-path and cover effects | yes (browser; Cloudflare blocks plain fetch) |
| 3 | CodePen: preloader search | https://codepen.io/search/pens?q=preloader | thousands of small openings with live HTML/CSS/JS source; also search "page intro", "reveal", "curtain" | yes (browser) |
| 3 | Shadertoy: transition search | https://www.shadertoy.com/results?query=transition | GLSL transitions and reveals with readable source; WebGL is not buildable here, so take the quality (the shape of the wipe, the timing), not the code | yes (browser) |
| 3 | Offscreen Canvas | https://offscreencanvas.com/issues/ | weekly written breakdowns of creative front-end effects with source code (particles, physics, image effects) | yes |
| 3 | Pouët: JavaScript demos | https://www.pouet.net/prodlist.php?type%5B%5D=demo&platform%5B%5D=JavaScript&order=views | demoscene browser demos, whose whole art is the first seconds: rankings, comments, links to video and source; many run in plain canvas | yes |
| 3 | GSAP showcase | https://gsap.com/showcase/ | a list of sites built with GSAP (A24 by Ravi Klaassens, Illoca by Unseen); no commentary, but each live site's timeline code can be read | no (links only; follow the live link) |
| 4 | Hasselblad: photographer stories | https://www.hasselblad.com/inspiration/stories/ | how a camera maker opens a page on one photographer: full-width photograph first, name and title beneath, then a written story; landscape work included | yes |
| 4 | Magnum Photos: Arts & Culture | https://www.magnumphotos.com/arts-culture/ | written stories built on photographs, opening on one picture then title and byline; the printed-journal rhythm on screen | yes |
| 4 | Internet Archive: scanned photobooks | https://archive.org/details/seasonsinrockies0000wigg | whole landscape photobooks page by page with OCR text (search: subject "Landscape photography", texts); how a printed book opens: endpaper, half-title, frontispiece plate, first spread | yes |
| 4 | Fonts In Use: title sequences | https://fontsinuse.com/tags/397/title-sequences | 386 title sequences as stills with typeface identification and short notes (Bullitt by Pablo Ferro, Snowpiercer); good for lettering, thin on movement | yes (type facts, little motion) |
| 4 | Eye Magazine | https://www.eyemagazine.com/feature/article/magnum-photos | design criticism free to read, e.g. five designers on the Magnum site as book-like web design; search the site for film titles and photobooks | yes |

Checked and left out: Godly (now redirects to recent.design, thumbnails only); Siteinspire (thumbnails, though /websites/category/photography is a useful filter); Letterform Archive online (offline for maintenance on 2026-10-08); Movie Title Stills Collection annyas.com (unreachable); Demozoo, OpenProcessing, MoMA exhibition history, LensCulture (blocked a plain fetch; not verified); Experiments with Google (one-line descriptions, no code links); Wikipedia "Film leader" (readable, but sits on top of the excluded counter and filmstrip).
