# 照片放這裡 · Where photos go

把照片丟進對應的資料夾就好,其他交給 Claude。
Drop photos into the matching folder — Claude handles the rest.

```
images/
  portfolio/     ← 最強作品(作品集首頁的照片牆)Greatest hits for the Gallery wall
  spain/         ← 巴賽隆納等  Barcelona etc.
  japan/         ← 大阪、京都、富士山、東京、北海道
  taiwan/  uk/  france/  germany/  switzerland/
  south-korea/  hong-kong/  china/  singapore/  vietnam/  dubai/
  australia/  new-zealand/  usa/
```

## 幾件事 · A few notes

- **原始大小就好** — 直接丟全解析度檔案沒問題,Claude 會自動縮成網頁用尺寸(長邊約 2000px),
  原檔不會被改動。Drop full-res files; Claude makes web-sized copies and never alters your originals.
- **檔名不用管** — 5S5A1234.jpg 這種也可以,Claude 會重新命名。Filenames don't matter.
- **只放自己拍的** — 網站是公開的,別人的參考圖(小紅書等)不要放進來。
  Only your own photos — the site is public.
- 想指定某張當首頁大圖/國家封面,跟 Claude 說就好。Tell Claude which shot should be the hero or a country cover.

`.svg` 檔是暫時的佔位圖,之後會被真照片取代。The `.svg` files are placeholders, to be replaced.
