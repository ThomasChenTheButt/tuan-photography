# 網站用的照片 · The site's photos

這個資料夾是 Claude 管的，你不需要打開。
This folder is managed by Claude. You don't need to open it.

- `web/` 是網站顯示的縮小版（長邊 2400px），`web/1280/` 和 `web/640/` 是給小螢幕的更小版本。
  `web/` holds the web-sized copies; `web/1280/` and `web/640/` are smaller ones for small screens.
- **你的原檔在 `originals/`**，要加照片請放那裡。
  **Your originals live in `originals/`.** Add photos there.
